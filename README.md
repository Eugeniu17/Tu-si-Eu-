# Între noi — Journey 4.0

Versiune complet redesenată pentru Eugeniu și Alina.

## Ce este nou
- design luminos, tip jurnal / carte poștală;
- hartă animată Paris → Menton fără text suprapus;
- fiecare zi este un traseu în 6 pași, nu un formular lung;
- trei motive de rugăciune zilnic;
- două sâmbete speciale pentru post și rugăciune;
- două duminici speciale pentru biserică și recunoștință;
- plic care se închide și primește o pecete în formă de inimă;
- două jumătăți de inimă: una pentru fiecare răspuns;
- legătură de confirmare care marchează că și celălalt a terminat ziua;
- zilele se deschid după 00:00, inclusiv la 05:00 dimineața;
- mesaj pentru mâine, sigilat până la data următoare;
- progresul se salvează local pe fiecare telefon.
