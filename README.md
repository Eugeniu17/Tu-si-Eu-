# Între noi — versiune pentru GitHub de pe telefon

Încarcă toate aceste fișiere direct în rădăcina repository-ului:

```text
index.html
style.css
app.js
config.json
days.json
README.md
VERIFICARE.md
```

Nu crea foldere `css`, `js` sau `data`. Toate căile au fost adaptate pentru fișiere aflate împreună.

## GitHub Pages

1. `Settings` → `Pages`.
2. `Deploy from a branch`.
3. Branch `main`, folder `/(root)`.
4. `Save`.
5. Așteaptă 1–3 minute și reîncarcă pagina.

Răspunsurile sunt păstrate local în browser.
